# Online Movie Ticket Booking and Management System
A DBMS mini project implementing an Online Movie Ticket Booking and Management System using ER modeling, relational schema design, normalization, and advanced SQL queries for booking operations and revenue analysis.

## Project Overview
This project is a DBMS-based Online Movie Ticket Booking and Management System developed using MySQL.  
It is designed to manage theatres, screens, movies, shows, customers, and ticket bookings efficiently.

The system supports booking operations and performs revenue analysis using SQL queries such as joins, aggregations, and subqueries.

---

## Database Name
movie_ticket_booking_system

---

## Tables Included

1. Theatres
2. Screens
3. Movies
4. Shows
5. Customers
6. Bookings

---

## Relationships

- One Theatre can have multiple Screens.
- One Screen can host multiple Shows.
- One Movie can have multiple Shows.
- One Show can have multiple Bookings.
- One Customer can make multiple Bookings.

---

## Features

- Structured relational schema design
- ER modeling
- Primary and Foreign key constraints
- Ticket booking management
- Revenue calculation
- Analytical SQL queries (Beginner, Intermediate, Advanced)

---

## Technologies Used

- MySQL
- SQL
- ER Modeling (dbdiagram.io)

---

## How to Run the Project

1. Execute `schema.sql` to create database and tables.
2. Execute `insert_values.sql` to insert sample data.
3. Execute `queries.sql` to run project queries.
